# Repository guidance for coding agents

- `agents/<name>/` is the source for each agent: `AGENT.md` (the definition) and `skills.json` (the skills it imports and the AI-SKILLS revision they are pinned to).
- Keep an agent to what is specific to it. A behaviour that could apply elsewhere belongs in AI-SKILLS as a skill, which the agent then imports. Do not copy skill text into an agent or into this repository.
- Name every imported skill in `AGENT.md`, in code formatting, at the step where the agent should use it. `npm run validate` fails otherwise.
- `AGENT.md` stays tool-neutral. Tool formats live only in `targets/`. Before changing an adapter, reread that tool's documentation and update `docs/TARGETS.md` with what you checked and when.
- Every agent has a semantic version in `metadata.version`. A change to an agent needs a bump and a `versions` entry in `registry/agents.json` saying what the new version is expected to do. `evaluations` there record which target and model tested a version.
- `docs/CATALOG.md` is generated by `npm run catalog`; do not edit it by hand.
- This repository is public. Never add secrets, private paths or account names.
- The install command must never write outside the project folder, never replace a file it did not write unless `--force` is given, and never install for a tool the user did not name.

Before finishing a change, run `npm run validate`, `npm run catalog:check` and `npm test`.
